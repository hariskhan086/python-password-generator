# Python Password Generator

A simple password generator built with Python as part of my Python learning journey.

## What this project does

This program generates random passwords based on user-selected options such as:

- Number of letters
- Number of symbols
- Number of numbers

The program then combines these characters and creates a randomized password.

## Concepts I practiced

While building this project, I practiced:

- Python variables
- `input()`
- `for` loops
- Lists
- `random` module
- `random.choice()`
- List methods
- String manipulation
- Basic programming logic

## How to run

Make sure Python is installed on your computer.

Clone the repository:

```bash
git clone https://github.com/hariskhan086/python-password-generator.git
```

Open the project folder and run:

```bash
python Password-generator.py
```

## Example

The program asks the user how many letters, symbols, and numbers they want in their password.

It then generates a random password based on those choices.
